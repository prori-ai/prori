# Prori (prori.ai)

**Great products deserve to be seen.**

[Prori](https://prori.ai) (`prori.ai`) is an all-in-one AI creation and product growth platform connecting brands, creators, and AI agents — combining 30 dedicated AI image and video tools, AI audio and HTML5 game creation, a searchable directory of 230,000+ software and AI products, creator ad placements and promotion campaigns, and the Prori Desktop & Chrome growth agent (**BNBOT**).

This organization (`prori-ai`) is the official GitHub home of [Prori](https://prori.ai).

## Inside Prori

1. **AI Creative Studios** — 15 dedicated [AI Image tools](https://prori.ai/ai-image) (Face Swap, Character Swap, Relight, Inpaint, Upscale, Remove Background), 15 [AI Video tools](https://prori.ai/ai-video) (Cinema, Talking Portrait, Reframe, URL to Ad, Shorts, Edit, Upscale), [AI Audio](https://prori.ai/ai-audio), and [playable HTML5 games](https://prori.ai/games).
2. **230,000+ Product Directory** — discover software and AI products across hundreds of [categories](https://prori.ai/topics), compare alternatives, and track daily launches.
3. **Brand & Creator Growth** — [creator ad placements](https://prori.ai/ads) and [verified promotion campaigns](https://prori.ai/promote) across X, YouTube, TikTok, Instagram, and Reddit.
4. **Prori Agent (BNBOT)** — macOS desktop app, Chrome side-panel extension, and remote MCP server (`https://mcp.bnbot.ai/mcp`).
